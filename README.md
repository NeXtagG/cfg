# cfg — Конфиги

Найти любой конфиг на системе и сразу открыть его в `nano`, а если прав не
хватает — в `sudo nano`. Две версии: `cfg` для терминала (fzf) и `cfg-gui`
с окном на GTK4/libadwaita («Конфиги» в меню).

Ищет в `~` (dotfiles, `~/.config`, ярлыки) и в `/etc`, пропуская кэши
браузеров, Electron и прочий мусор.

## Установка

```bash
git clone https://github.com/NeXtagG/cfg && cd cfg
bash install.sh
```

Ставит `cfg` и `cfg-gui` в `~/.local/bin` и ярлык «Конфиги» в меню.

Зависимости: `fzf` (для `cfg`), `bat` — по желанию для подсветки превью,
PyGObject + `gtk4` + `libadwaita` (для `cfg-gui`). Если установлен `vte4`,
nano открывается прямо в окне, иначе — в отдельном терминале
(`xdg-terminal-exec`).

## cfg в терминале

```bash
cfg              # поиск по всем конфигам
cfg hypr         # сразу с запросом "hypr"
cfg -u | -e      # только ~ / только /etc
cfg -l [запрос]  # просто список путей
```

| Клавиша | Действие |
|---|---|
| Enter | открыть: nano, если файл можно писать, иначе sudo nano |
| Ctrl-S | принудительно sudo nano |
| Alt-U / Alt-E / Alt-A | показать ~ / /etc / всё |
| Ctrl-R | пересканировать |
| Ctrl-Y | скопировать путь |
| Esc | выход |
